# UI redesign plan

Status: proposed, November 15, 2026. The rules, kit, theme, front end, depth card, desktop HUD, run menu, death and confirmation are built and described in [user interface](../user-interface.md). This plan covers what remains: the touch HUD and the later screens. It follows that document's four rules.

## Decided

- **Four run slots stay**, so several runs can be played in parallel.
- **The HUD must suit a landscape touch screen.** The bottom-left corner is the left thumb's steering stick and stays empty on desktop; the bottom-right corner belongs to the right thumb's actions. Nothing else may claim either.
- **The debug menu reserves no space.** It ships only in development builds and may overlap the HUD.

## Touch HUD

The built HUD keeps its corners on a landscape phone, with these changes:

- **Readouts a third larger**: the vitals, depth, gold and feed, so they read at arm's length.
- **Actions as round thumb buttons with icons, never words:** attack in the bottom-right corner, the second hand action and the off hand around it, the dodge darts above, the quick slots up the right edge.
- **A context button:** the gold hand appears beside the actions only while a door, chest or item is in reach, and does whatever that offers. It replaces the key prompt.
- **No pause button:** leaving the app pauses and saves, as closing the window does.
- **The steering stick** takes the bottom-left corner.

The actions get two layouts over the same slots: the HUD's row with key or button glyphs (built), and the thumb buttons. New kit pieces: round action buttons; the hand and dodge icons exist. Acceptance: reviewed as a mockup, then built together with touch input.

## Run menu follow-ups

The run menu is built ([user interface](../user-interface.md#in-run-screens)). Left for later:

- **Gamepad glyphs:** the key row shows keyboard keys only; `KeyBinding` has the Xbox table but nothing switches to it.
- **Stacks:** splitting and merging stacks went with the context menu. Stacks merge on pickup; add a prompt only if playtests miss it.
- **Item lines:** `ItemDetailsView` still lists raw modifiers ("+2 Min Damage", "+5 Max Damage"); fold them into one line per item ("Damage 2–5 · One-handed").
- **The combat harness** has no run menu; add it once a harness scenario needs gear changes by hand.

## Later

- **Credits** generated from `assets/ATTRIBUTIONS.json`: every pack with `attribution_required`, and both fonts' OFL notices. Required before any release.
- **Settings:** display and controls still need screens and theme work. Audio preferences are available from the title and System menus. See [audio settings](../audio-system.md#components-and-mix).
- **Menu stage:** a more dramatic scene (stronger light and shadow, a grander room, more effects such as torch smoke and light shafts beside the embers); Continue's hero wearing the run's saved gear rather than the class's starting kit; a slow camera drift; the entrance of the run's current realm once realms settle.
- **Kit resolution:** render the kit at 2× and draw it at half scale, so frames stay crisp on 1440p and 4K windows.
- **Threaded first load:** load `main.tscn` with `ResourceLoader.LoadThreadedRequest` so the depth card's pips keep moving; floor generation stays on the main thread. Measure first: a floor builds in well under a second.
- **Interface sounds:** extend the existing Kenney button press cues with deliberate hover, open and close feedback where useful.

## Asset rules

Interface art is generated by `asset-studio/ui/ui_kit.py`, so it is CC0 by construction. Third-party kits were reviewed and rejected: KayKit has no free UI kit; Kenney's Fantasy UI Borders are thin pixel borders; Lamoot's RPG GUI kit is CC-BY and low resolution; Cinder UI forbids redistributing its files, which a public repository does. Fonts and later sounds must be CC0 or similarly permissive and openly downloadable, per [the asset rules](../../assets/AGENTS.md).

## Open decisions

- The realms are provisional, so the depth card shows only the depth; a realm name can join it once they settle.
